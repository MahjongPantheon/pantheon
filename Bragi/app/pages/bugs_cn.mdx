## 报告错误和问题

- 打开 <a href='https://github.com/MahjongPantheon/pantheon/issues' target='_blank'>Pantheon GitHub 仓库的 Issues 页面</a>。
- 点击 **New issue**。您可能需要先登录 GitHub。
- 填写 **Title** 和 **Description**，描述问题或建议，最好使用英语。
- 可将文件和截图拖入描述框以添加附件。
- 点击 **Submit new issue** 提交。

您随时可以在 <a href='https://github.com/MahjongPantheon/pantheon/issues'>Issues 页面</a>查看处理进度。

### 有问题想咨询开发团队，或不想注册 GitHub 账号？

您可以使用以下支持群聊：

- <a href='https://t.me/pantheon_support'>Telegram（主要使用俄语）</a>
- <a href='https://discord.gg/U5qBkexfEQ'>Discord（使用英语）</a>
