## 오류와 문제 신고

- <a href='https://github.com/MahjongPantheon/pantheon/issues' target='_blank'>Pantheon GitHub 저장소의 Issues 페이지</a>를 엽니다.
- **New issue**를 누릅니다. GitHub 로그인이 필요할 수 있습니다.
- **Title**과 **Description**에 문제나 제안을 가능하면 영어로 적습니다.
- 파일과 스크린샷을 설명란으로 끌어다 놓아 첨부할 수 있습니다.
- **Submit new issue**를 눌러 제출합니다.

진행 상황은 <a href='https://github.com/MahjongPantheon/pantheon/issues'>Issues 페이지</a>에서 언제든 확인할 수 있습니다.
