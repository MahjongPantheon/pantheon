## 시작하기와 계정 도움말

<a href={env.urls.tyr}>모바일 도우미</a>로 대국을 기록하고 <a href={env.urls.sigrun}>순위표와 통계</a>에서 결과를 확인하며 <a href={env.urls.forseti}>프로필 및 관리 패널</a>에서 계정과 이벤트를 관리합니다. 모든 서비스에서 같은 계정을 사용합니다.

목차: [이벤트 유형](#event-modes), [계정 생성](#sign-up), [참가 등록](#registration), [프로필](#profile), [비밀번호](#password), [자주 묻는 질문](#questions). 스크린샷은 영어 화면과 가상의 플레이어, TEST 이벤트를 사용합니다. 누르면 원본 크기로 열립니다.

<h3 id='event-modes'>어떤 이벤트 유형을 선택하나요?</h3>

**이벤트(event)**에는 별도의 선수 목록, 규칙과 순위표가 있습니다. **세션(session)**은 한 테이블의 대국을 뜻하며 대회 관리에서는 동시에 진행하는 전체 테이블을 뜻할 수도 있습니다. 조작 화면의 **round**는 한 국입니다.

- **로컬 순위표(클럽):** 플레이어가 직접 상대와 시작 좌석을 정해 대국을 시작하고 각 국을 기록합니다. 테이블은 독립적으로 진행하며 공통 타이머가 없습니다. 운영 중에도 관리자가 선수를 추가할 수 있습니다.
- **대회:** 관리자가 참가자와 자리를 준비하고 타이머로 모든 테이블을 시작한 뒤 완료 세션을 함께 승인합니다. 무작위, 스위스식, 간격 또는 사전 지정 배정을 사용할 수 있습니다.
- **온라인 이벤트:** 지원하는 외부 플랫폼과 패보에서 결과를 가져옵니다. 필요한 플랫폼과 계정은 주최자에게 확인하세요. 실제 테이블에서 기록하는 절차와 다릅니다.

<h3 id='sign-up'>계정을 어떻게 만드나요?</h3>

1. <a href={`${env.urls.forseti}/profile/signup`}>새 계정 등록</a>을 엽니다.
2. 수신 가능한 이메일, 플레이어 이름과 안전한 비밀번호를 입력합니다. 주최자가 찾기 쉽도록 알아볼 수 있는 이름과 성을 사용하세요.
3. 개인정보 처리방침을 읽고 동의한 뒤 **새 계정 등록**을 누릅니다.
4. 인증 메일의 확인 링크를 열고 로그인합니다.
5. <a href={`${env.urls.forseti}/profile/manage`}>프로필</a>을 확인하고 주최자에게 알립니다.

<GuideScreenshot name="account-signup" alt="이메일, 이름, 비밀번호와 개인정보 동의가 있는 가입 화면. 하나의 계정으로 여러 이벤트에 등록할 수 있습니다." caption="이메일, 이름, 비밀번호와 개인정보 동의가 있는 가입 화면. 하나의 계정으로 여러 이벤트에 등록할 수 있습니다." />

메일이 없으면 스팸함과 주소를 확인하세요. 계속 활성화할 수 없으면 관리자에게 문의하세요. 기존 계정이 있다면 복구를 사용하세요. 중복 계정은 대국 이력을 나눕니다. 대회장에 오기 전에 계정을 만드세요.

<h3 id='registration'>클럽이나 대회에 어떻게 참가하나요?</h3>

**회원가입은 Pantheon 계정을 만드는 일이고, 선수 등록은 그 계정을 특정 이벤트에 추가하는 일입니다.** 가입만으로 명단에 추가되지 않습니다.

프로필의 **System ID** 또는 플레이어 이름을 주최자에게 전달하세요. 주최자가 **선수 관리**에서 추가하면 도우미에 로그인해 이벤트를 선택합니다. 별도로 안내된 참가 신청이나 결제도 완료하세요.

<h3 id='profile'>프로필은 어떻게 관리하나요?</h3>

1. <a href={env.urls.forseti}>프로필 및 관리 패널</a>에 로그인해 <a href={`${env.urls.forseti}/profile/manage`}>내 계정</a>을 엽니다. 도우미 설정에도 개인 영역 링크가 있습니다.
2. **플레이어 이름**, 국가, 도시, 선택적 연락처나 Tenhou 정보를 수정합니다. Tenhou는 공개 사용자 이름만 입력하고 로그인 문자열을 넣지 마세요.
3. 아바타 옵션을 켜고 256 KB 이하의 정사각형 이미지를 선택합니다. 다른 비율은 중앙 정사각형으로 잘립니다.
4. **변경 저장**을 누르고 완료 표시를 기다립니다.

<GuideScreenshot name="account-profile" alt="이름, System ID, 국가, 도시와 아바타가 있는 프로필. System ID는 계정을 고유하게 식별합니다." caption="이름, System ID, 국가, 도시와 아바타가 있는 프로필. System ID는 계정을 고유하게 식별합니다." height={930} />

이메일은 여기서 읽기 전용입니다. 변경은 최고 관리자에게 문의하세요. 계정 삭제는 계정 데이터를 지우는 작업이며 이벤트 탈퇴나 비밀번호 변경에 필요하지 않습니다.

<h3 id='password'>비밀번호를 바꾸거나 복구하려면?</h3>

분실한 경우와 새 비밀번호로 변경하는 경우 모두 이메일 복구를 사용합니다.

1. <a href={`${env.urls.forseti}/profile/resetPassword`}>비밀번호 복구</a>에 계정 이메일을 입력하고 제출합니다.
2. 메일의 링크를 엽니다.
3. 확인 화면에서 **내 비밀번호 초기화**를 누르면 기존 비밀번호가 작동하지 않습니다. 페이지를 떠나기 전에 다음 단계를 완료하세요.
4. 새 안전한 비밀번호를 입력하고 **비밀번호 갱신**을 누릅니다.
5. 성공 메시지 후 새 비밀번호로 로그인합니다.

<GuideScreenshot name="account-password" alt="이메일로 복구를 요청하는 화면. 메일 링크에서 새 비밀번호를 지정합니다." caption="이메일로 복구를 요청하는 화면. 메일 링크에서 새 비밀번호를 지정합니다." />

만료되거나 사용한 링크라면 다시 요청하세요. 메일이 없으면 스팸함을 확인합니다.

<h3 id='questions'>자주 묻는 질문</h3>

**이벤트가 도우미에 없어요.** 주최자에게 현재 이벤트에 정확한 계정이 등록되었는지 확인받고 목록을 새로고침하거나 설정에서 다시 선택하세요.

**주최자가 저를 못 찾아요.** 알아볼 수 있는 이름을 저장하거나 System ID를 전달하세요. 계정을 추가로 만들지 마세요.

**결과는 어디 있나요?** <a href={env.urls.sigrun}>순위표와 통계</a>에서 이벤트를 선택하세요. 대회 결과는 관리자 승인 후 공개 설정에 따라 표시됩니다.
