## 使用移动助手

在手机上打开<a href={env.urls.tyr}>移动助手</a>。您需要已激活的账号并已加入活动，参见<Link to='/getStarted'>开始使用与账号帮助</Link>。

本页：[选择活动](#event)、[俱乐部对局](#club)、[比赛](#tournament)、[录入一局](#recording)、[历史与纠错](#corrections)。截图为英语界面和虚构玩家，点击可放大。

<h3 id='event'>1. 登录并选择活动</h3>

用邮箱和密码登录，从列表中选择俱乐部排名或比赛。列表为空或活动缺失时，请主办方检查注册情况；仅创建 Pantheon 账号还不够。

<GuideScreenshot name="mobile-events" alt="移动助手活动列表。请选择您实际参加的活动。" caption="移动助手活动列表。请选择您实际参加的活动。" mobile />

主页显示活动名称和操作。如有进行中的对局，助手可能直接打开桌面；点击主页按钮返回活动菜单。

<GuideScreenshot name="mobile-home" alt="俱乐部主页的新对局和统计按钮。开始或记录前请确认活动名称。" caption="俱乐部主页的新对局和统计按钮。开始或记录前请确认活动名称。" mobile />

点击齿轮进入设置，可更改语言和主题、打开个人中心、切换活动或退出。**单设备模式**适合全桌共用一部手机记录，不要求每人操作自己的手机。

<GuideScreenshot name="mobile-settings" alt="语言、主题、活动和单设备模式设置。账号与密码操作见账号指南。" caption="语言、主题、活动和单设备模式设置。账号与密码操作见账号指南。" mobile />

<h3 id='club'>2. 开始俱乐部对局</h3>

1. 在活动主页点击**新对局**。
2. 从已注册名单中按**东–南–西–北**顺序选择玩家，三人麻将为**东–南–西**。必要时清空重新选择。
3. 如需随机初始座位，点击打乱按钮并共同检查顺序。
4. 核对姓名和风位后开始。只需一人创建；其余玩家刷新助手即可进入同一桌。

<GuideScreenshot name="mobile-new-game" alt="已选四名玩家的新对局，带打乱和开始按钮。开始前核对玩家及初始风位。" caption="已选四名玩家的新对局，带打乱和开始按钮。开始前核对玩家及初始风位。" mobile />

俱乐部没有统一计时器。结束条件依活动规则，可能涉及东风战、半庄、连庄、目标分或击飞。选错玩家时，请在录入任何一局前让管理员删除空对局。

<h3 id='tournament'>3. 加入比赛桌</h3>

排座由管理员生成，不要通过**新对局**创建比赛桌。排座就绪后，查看桌号和初始风位，到桌后核对所有玩家。

<GuideScreenshot name="mobile-tournament-ready" alt="管理员启动计时器前的比赛桌分配。按指定座位入座，等待开始信号。" caption="管理员启动计时器前的比赛桌分配。按指定座位入座，等待开始信号。" mobile />

管理员统一启动所有桌和计时器，助手显示倒计时。时长和超时规则依活动设置：时间到后可能打完当前局、再打一局，或自然结束整场。遵循主办方说明和助手状态，不存在通用的 75 分钟规则。

<GuideScreenshot name="mobile-tournament-timer" alt="比赛桌中的倒计时。计时与额外时间由主办方管理。" caption="比赛桌中的倒计时。计时与额外时间由主办方管理。" mobile />

本桌结束后，等待管理员确认全部场次。请在确认前报告错误。结果按可见性设置公布；下一轮排座生成后才出现新的桌位。

<h3 id='recording'>4. 录入一局</h3>

由一人录入，全桌共同检查。所有设备共享同一对局状态，不要用多部手机重复录入。

<GuideScreenshot name="mobile-table" alt="桌面上的点数、风位和添加按钮。点击加号选择本局结果。" caption="桌面上的点数、风位和添加按钮。点击加号选择本局结果。" mobile />

1. 点击 **+**，按规则选择**荣和（Ron）**、**自摸（Tsumo）**、**荒牌流局**、**途中流局**、**犯规（Chombo）**或**流局满贯（Nagashi）**。双响或三响选择一次荣和，再勾选所有和牌者，不要拆成多局。

<GuideScreenshot name="mobile-outcome" alt="荣和、自摸、流局和犯规等结果选项。选择实际结束本局的结果。" caption="荣和、自摸、流局和犯规等结果选项。选择实际结束本局的结果。" mobile />

2. 荣和时选和牌者与放铳者，自摸时选和牌者，荒牌流局时选听牌者，犯规时选受罚者。在此界面同时标记本局所有立直宣言，再继续。

<GuideScreenshot name="mobile-players" alt="和牌者、放铳者与立直状态。立直须在选择役之前登记。" caption="和牌者、放铳者与立直状态。立直须在选择役之前登记。" mobile />

3. 为每位和牌者选择役。未勾选**副露手牌**时视为门前。多人和牌时逐一检查标签页。役与组合依规则变化；助手会禁用不兼容选项，但玩家仍须核对。
4. 设置总宝牌数和符数。部分符数会被所选役固定或限制。宝牌增加价值，但不能代替合法的役。如提示责任支付（包牌、pao），按要求选择。

<GuideScreenshot name="mobile-hand" alt="和牌编辑器中的役、宝牌和符数。逐一核对门前／副露状态及每位和牌者。" caption="和牌编辑器中的役、宝牌和符数。逐一核对门前／副露状态及每位和牌者。" mobile />

5. 前进到预览，将点数变化展示给其他玩家。此时解决争议；用返回修改，全桌同意后再点击勾号提交。

<GuideScreenshot name="mobile-preview" alt="提交前的点数变化预览。确认按钮才会保存本局。" caption="提交前的点数变化预览。确认按钮才会保存本局。" mobile />

提交后检查点数和局次。遇到网络问题先刷新并检查日志，确认未保存后再录入，避免重复。

<h3 id='corrections'>5. 查看历史并处理错误</h3>

通过桌面日志按钮查看各局，点击行展开详情；点击玩家点数可查看分差。

<GuideScreenshot name="mobile-log" alt="已展开详情的对局日志。先确认需要修改的具体一局。" caption="已展开详情的对局日志。先确认需要修改的具体一局。" mobile />

已提交的数据有误时请叫裁判或管理员，玩家不能自行撤销。裁判撤销最近一局后，全桌重新录入正确结果。较早的错误需要同时撤销并重录其后的各局，请先核对记录。

俱乐部对局结束后，应在任何玩家开始下一场之前联系管理员，否则可能无法重新打开结果。比赛中应在管理员确认场次之前报告。计时器归零不代表成绩已确认。

活动主页的**统计**或<a href={env.urls.sigrun}>排名与统计</a>可查看排名、已结束对局和玩家数据，可见范围取决于活动设置。
