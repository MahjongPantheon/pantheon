## Using the mobile assistant

Open the <a href={env.urls.tyr}>mobile assistant</a> on your phone. You need an activated Pantheon account
and registration in the event: see <Link to='/getStarted'>Getting started and account help</Link>.

On this page: [choose an event](#event), [club games](#club), [tournaments](#tournament),
[record a hand](#recording), and [history and corrections](#corrections).
Screenshots show the current interface with synthetic players. Tap a screenshot to open it at full size.

<h3 id='event'>1. Log in and choose an event</h3>

Log in with your account email and password. Select the club rating or tournament from the event list.
If the list is empty or an event is missing, ask the organizer to check your registration; signing up for
Pantheon alone does not add you to an event.

  <figcaption>Choose the event you are playing in.</figcaption>
</figure>

The home screen shows the event name and available actions. When you have an ongoing game, the assistant
may open the table directly; use the home button to return to the event menu.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-home.png'><img src='/assets/img/guides/en/mobile-home.png' width='390' height='844' alt='Club event home screen with New game and Statistics buttons' loading='lazy' /></a>
  <figcaption>Check the event name before starting or recording a game.</figcaption>
</figure>

Open settings with the gear button. Here you can change language and theme, open your personal area,
switch events, or log out. **Single device mode** is useful when one phone records for the whole table:
it presents the table for that use rather than requiring every player to operate a phone.

  <figcaption>Account details and password recovery are covered in the account guide.</figcaption>

<h3 id='club'>2. Start a club game</h3>

1. On the event home screen, press **New game**.
2. Select the participants from the registered player list. Fill the initial seats in **East–South–West–North**
   order, or **East–South–West** for sanma. Use clear to start the selection again if necessary.
3. If you want random initial seats, use the shuffle button and check the resulting order together.
4. Verify the names and winds, then press the start button. Only one player needs to start the game.
   Other participants can refresh their assistant to open the same table.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-new-game.png'><img src='/assets/img/guides/en/mobile-new-game.png' width='390' height='844' alt='New club game with four selected players and shuffle and start controls' loading='lazy' /></a>
  <figcaption>Check all participants and initial winds before starting.</figcaption>
</figure>

Club games have no shared tournament timer. They finish according to the event rules, which may include
East-only play, South-round play, dealer continuation, target points or bankruptcy.
If the wrong people were selected, ask an administrator to remove the empty game before recording hands.

<h3 id='tournament'>3. Join a tournament table</h3>

The administrator generates seating; you do not start a tournament table with **New game**.
When seating is ready, check your table number and initial wind, find your table and verify the participants.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-tournament-ready.png'><img src='/assets/img/guides/en/mobile-tournament-ready.png' width='390' height='844' alt='Tournament table assignment before the administrator starts the timer' loading='lazy' /></a>
  <figcaption>Take the assigned seat and wait for the start signal.</figcaption>
</figure>

The administrator starts the timer and all tables together. The assistant shows the countdown.
The duration and ending policy are configured for the event: when time runs out, you may need to finish the
current hand, play one more hand, or continue until the game ends naturally. Follow the organizer's announcement
and the assistant's status; there is no universal 75-minute rule for every event.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-tournament-timer.png'><img src='/assets/img/guides/en/mobile-tournament-timer.png' width='390' height='844' alt='Tournament game screen with the shared countdown running' loading='lazy' /></a>
  <figcaption>The organizer controls the tournament timer and any extra time.</figcaption>
</figure>

After your table finishes, wait for the administrator to approve all sessions. Report errors before approval;
results are published according to event visibility settings after that step. The next table assignment
appears when the next seating is generated.

<h3 id='recording'>4. Record a hand</h3>

One person enters the result; everyone at the table should check it. The same game state is shared across
participants' assistants. Do not enter the same hand on several phones.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-table.png'><img src='/assets/img/guides/en/mobile-table.png' width='390' height='844' alt='Current game showing player scores, winds and the add-hand button' loading='lazy' /></a>
  <figcaption>The plus button opens the outcome menu.</figcaption>
</figure>

1. Press **+** and choose the outcome: **Ron**, **Tsumo**, **Exhaustive draw**, **Abortive draw**, **Chombo**
   or **Nagashi**, as available under the event rules. For double or triple ron, choose **Ron**, then select
   all winners rather than entering separate hands.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-outcome.png'><img src='/assets/img/guides/en/mobile-outcome.png' width='390' height='844' alt='Hand outcome menu with Ron, Tsumo, draw and Chombo choices' loading='lazy' /></a>
  <figcaption>Select the result that actually ended the hand.</figcaption>
</figure>

2. Select the winners and the discarder for ron, or the winner for tsumo. For an exhaustive draw, select
   the tenpai players. For chombo, select the penalized player or players. Select all players who declared
   riichi on this hand before continuing; use the status controls on this screen.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-players.png'><img src='/assets/img/guides/en/mobile-players.png' width='390' height='844' alt='Player status selection with the winner, discarder and riichi declaration selected' loading='lazy' /></a>
  <figcaption>Riichi declarations belong to this step, before choosing yaku.</figcaption>
</figure>

3. For each winning hand, choose its yaku. Hands are treated as closed unless you select **Open hand**.
   For multiple winners, check each winner's hand tab. The available yaku and their combinations depend on
   the event rules; the assistant disables incompatible selections, but players must still verify the hand.
4. Select the total number of dora and the fu value using their controls on the hand screen.
   Some fu choices are fixed or restricted by the selected yaku. Dora adds value but does not replace the
   requirement for a valid yaku. Complete any responsibility-payment (pao) selection when requested.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-hand.png'><img src='/assets/img/guides/en/mobile-hand.png' width='390' height='844' alt='Winning hand editor with selected yaku and dora and fu controls' loading='lazy' /></a>
  <figcaption>Check the open or closed state, yaku, dora and fu for each winner.</figcaption>
</figure>

5. Go forward to the preview. Show the point changes to the other players and resolve disagreements now.
   Use back to correct an entry; confirm with the check button only when the table agrees.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-preview.png'><img src='/assets/img/guides/en/mobile-preview.png' width='390' height='844' alt='Hand preview showing point changes before submission' loading='lazy' /></a>
  <figcaption>The preview is a check before recording; the confirmation button submits the hand.</figcaption>
</figure>

After submission, check the updated scores and round on the table screen. If a connection problem occurs,
refresh and check whether the hand is already in the log before trying to enter it again.

<h3 id='corrections'>5. Check history and handle mistakes</h3>

Use the game-log button on the table screen to see recorded hands. Tap a row to expand its details.
Tapping a player's score on the table lets you inspect score differences.

<figure className='guideScreenshot mobile'>
  <a href='/assets/img/guides/en/mobile-log.png'><img src='/assets/img/guides/en/mobile-log.png' width='390' height='844' alt='Game log with a recorded hand expanded to show its details' loading='lazy' /></a>
  <figcaption>Use the log to agree which hand needs correction.</figcaption>
</figure>

If a submitted hand is wrong, call a referee or administrator. Players cannot cancel it themselves.
The referee cancels the latest hand, and the table records the correct result. Correcting an older hand
requires cancelling and re-entering the later hands too, so agree on their details first.

For a completed club game, contact the administrator before anyone starts another game: later play can prevent
reopening the previous results. For a tournament, report the error before the administrator approves sessions.
A timer reaching zero does not replace that approval step.

For standings, finished games and player statistics, use **Statistics** on the event home screen or open
<a href={env.urls.sigrun}>ratings and statistics</a>. Visibility depends on the event settings.
