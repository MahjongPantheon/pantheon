## 클럽과 대회 관리

<a href={env.urls.forseti}>관리 패널</a>에 로그인해 **내 이벤트**에서 선택합니다. **작업** 메뉴나 왼쪽 메뉴의 **선수 관리**, **대국 관리**, **설정**을 사용합니다. 보이지 않으면 관리자에게 **권한 관리**에서 접근을 허용해 달라고 요청하세요. 참가만으로 관리 권한을 얻지는 않습니다.

목차: [클럽](#club), [대회](#tournament), [사전 지정](#predefined). 계정과 유형은 <Link to='/getStarted'>시작하기</Link>를 참고하세요. 그림은 영어 화면의 가상 TEST 이벤트이며 누르면 확대됩니다.

<h3 id='club'>클럽: 선수 등록과 대국 관리</h3>

#### 1. 이벤트 생성 또는 선택

**새 이벤트 생성**에서 **로컬 순위표**를 선택하고 이름, 기본 규칙, 시간대와 나머지 설정을 확인해 저장합니다. 연습용은 이름에 TEST를 넣으세요. 클럽 이벤트는 여러 모임에 걸쳐 계속 사용할 수 있으며 테이블은 독립적으로 시작하고 끝납니다.

#### 2. 선수 추가

1. 먼저 <a href='/ko/getStarted#sign-up'>계정 생성과 활성화</a>를 요청합니다.
2. **선수 관리** 검색란에 이름이나 `#`와 System ID를 입력합니다.
3. 올바른 결과를 선택하고 비슷한 이름이면 ID를 확인합니다.
4. 즉시 목록에 나타나며 도우미에서 이벤트를 선택할 수 있습니다. 다른 선수도 반복하고 검색되지 않으면 프로필 이름이나 System ID를 확인합니다.

<GuideScreenshot name="club-players" alt="클럽 선수 검색과 목록. 기존 계정을 이벤트에 등록하는 작업이며 회원가입과 별개입니다." caption="클럽 선수 검색과 목록. 기존 계정을 이벤트에 등록하는 작업이며 회원가입과 별개입니다." height={960} />

클럽 운영 중에도 등록 가능합니다. 실수로 추가했다면 가능한 경우 제거 아이콘으로 삭제하세요. 명단에서 빼도 대국은 취소되지 않습니다. 관리 권한은 **권한 관리**에서 별도로 지정합니다.

#### 3. 선수들이 대국 시작

도우미의 **새 대국**에서 등록 선수를 동–남–서–북(삼마: 동–남–서) 순으로 선택하고 필요하면 섞어 시작합니다. 공통 타이머나 자동 대회 배정은 없습니다. <a href='/ko/forPlayers#club'>플레이어 안내</a>를 참고하세요.

#### 4. 잘못 시작한 대국 삭제

1. **대국 관리**에서 선수 이름으로 테이블을 찾습니다.
2. 기록한 국이 없다면 **대국 삭제**를 누르고 확인합니다. 빈 대국 전체가 삭제됩니다.
3. 도우미를 새로고침하고 올바른 참가자와 자리로 다시 시작하도록 합니다.

<GuideScreenshot name="club-remove-game" alt="기록 전 빈 클럽 대국의 삭제 버튼. 한 국이라도 기록하면 사용할 수 없습니다." caption="기록 전 빈 클럽 대국의 삭제 버튼. 한 국이라도 기록하면 사용할 수 없습니다." />

기록 후에는 **마지막 국 취소(Cancel round)**로 바뀝니다. 선수들과 마지막 국을 확인하고 취소·확인한 뒤 올바른 결과를 입력합니다. 이전 오류는 이후 국을 최신부터 역순으로 취소하고 실제 순서대로 재입력해야 하므로 먼저 내용을 합의하세요. 전부 취소하면 빈 대국을 삭제할 수 있습니다.

<GuideScreenshot name="club-cancel-round" alt="마지막 클럽 국 취소 확인. 대국 전체가 아니라 마지막 국만 취소합니다." caption="마지막 클럽 국 취소 확인. 대국 전체가 아니라 마지막 국만 취소합니다." />

완료 대국의 **마지막 국과 결과 취소**는 마지막 국 및 공개 결과를 없애고 대국을 다시 엽니다. 서버가 허용할 때만 가능하며 참가자의 후속 대국이 있으면 막힐 수 있습니다. 다음 대국 전에 수정하세요.

<h3 id='tournament'>대회: 선수 명단부터 결과 승인까지</h3>

#### 1. 이벤트와 시간 설정

**대회**를 생성하거나 열고 규칙과 시간대를 정합니다. **대회 설정**에서 **세션 시간(분)**과 **종료 정책**을 확인해 저장합니다.

- 시간으로 중단하지 않고 자연 종료까지 진행.
- 시간 종료 후 현재 국을 마치고 종료.
- 현재 국을 마친 뒤 한 국 더 진행하고 종료.

<GuideScreenshot name="tournament-settings" alt="시간, 종료 정책, 사전 배정과 바람 설정. 시작 전 시간과 종료 방식을 공지하세요." caption="시간, 종료 정책, 사전 배정과 바람 설정. 시작 전 시간과 종료 방식을 공지하세요." height={1081} />

#### 2. 시작 전 등록 완료

**선수 관리**에서 이름이나 `#SystemID`로 추가합니다. 최초 배정 전에 명단을 완성하세요. 대회 세션 생성 시 추가·삭제가 잠기며 타이머 시작 전에도 변경할 수 없습니다.

자동 배정 대상은 **네 명**의 배수, 삼마는 **세 명**의 배수여야 합니다. 허용되는 상태에서 의자 아이콘으로 다음 배정에 포함하거나 제외합니다. 참가하지 않는 심판은 제외하세요. 제외해도 등록은 남습니다. 유효한 인원수를 유지하세요.

<GuideScreenshot name="tournament-players" alt="포함·제외 의자 아이콘이 있는 명단. 배정 전에 대상 선수를 확인하세요." caption="포함·제외 의자 아이콘이 있는 명단. 배정 전에 대상 선수를 확인하세요." height={960} />

대타가 필요하면 이름 옆 교체 기능에서 이벤트에 아직 등록되지 않은 사람을 선택합니다. 대타 점수 처리는 설정을 따릅니다. 본인이 돌아오면 결과 승인 전에 대타를 해제하세요.

#### 3. 자리 생성

**대국 관리**의 **준비 안 됨**은 인원 수정이 필요하다는 뜻입니다. **시작 전** 상태에서 방법을 선택해 확인합니다.

- **무작위:** 첫 세션부터 가능. 순위별로 묶지 않으며 재대결을 줄이려 하지만 새 상대를 보장하지 않습니다.
- **스위스식:** 이전 대국 이후 가능. 순위와 이력으로 비슷한 순위의 상대를 찾고 반복을 줄이지만 재대결은 가능합니다.
- **간격:** 이전 대국 이후 가능. 간격 1은 1–2–3–4, 5–6–7–8, 간격 2는 1–3–5–7, 2–4–6–8입니다.
- **다음 배정:** 사전 지정 이벤트에서 사용합니다. [아래](#predefined)를 참고하세요.

<GuideScreenshot name="tournament-seating" alt="첫 자동 배정은 무작위를 사용합니다. 스위스식과 간격에는 이전 대국이 필요합니다." caption="첫 자동 배정은 무작위를 사용합니다. 스위스식과 간격에는 이전 대국이 필요합니다." />

<GuideScreenshot name="tournament-interval" alt="간격 선택 확인. 이전 결과 승인 후 다음 세션의 방식을 고릅니다." caption="간격 선택 확인. 이전 결과 승인 후 다음 세션의 방식을 고릅니다." />

**배정 중**에는 기다립니다. **배정 준비 완료**에서 테이블과 시작 바람을 확인하세요. 선수는 도우미에서 자리를 볼 수 있고 순위 서비스의 **타이머와 자리**를 공용 화면에 표시할 수도 있습니다. 잘못되었다면 타이머 전에 **배정 초기화** 후 다시 생성합니다.

<GuideScreenshot name="tournament-ready" alt="생성된 테이블, 초기화와 타이머 시작. 착석은 가능하지만 아직 대국은 시작하지 않았습니다." caption="생성된 테이블, 초기화와 타이머 시작. 착석은 가능하지만 아직 대국은 시작하지 않았습니다." />

#### 4. 타이머 시작과 관리

모두 앉으면 **타이머 시작**을 누르고 확인하며 명확한 시작 신호도 줍니다. 모든 세션이 동시에 시작하고 **세션 시작됨** 상태가 됩니다.

전체 관리의 **시간 추가**는 모든 테이블에 1, 2, 3, 4, 5, 7분을 더합니다. 개별 테이블 안의 같은 버튼은 심판 처리 등으로 지연된 해당 테이블만 연장합니다. 확인 전에 대상을 살펴보세요. 현재 패널은 연장 기능을 제공하며 일시 정지나 타이머 초기화 버튼은 없습니다.

<GuideScreenshot name="tournament-timer" alt="전체 테이블 대상임을 명시한 연장 창. 개별 지연에는 해당 테이블 기능을 사용하세요." caption="전체 테이블 대상임을 명시한 연장 창. 개별 지연에는 해당 테이블 기능을 사용하세요." />

시간이 끝나면 설정한 종료 정책을 적용합니다. 0이 되어도 결과를 자동 승인하지 않습니다.

#### 5. 기록 수정

대상 테이블의 **마지막 국 취소**를 누르고 확인한 뒤 선수에게 새로고침과 재입력을 요청합니다. 가장 최근 국만 취소합니다. 종료한 테이블도 결과 승인 전에는 가능합니다.

<GuideScreenshot name="tournament-cancel-round" alt="대회 테이블의 마지막 국 취소 확인. 동기화된 대회 세션은 계속됩니다." caption="대회 테이블의 마지막 국 취소 확인. 동기화된 대회 세션은 계속됩니다." />

시작 전 배정을 버리려면 **배정 초기화**를 사용합니다. 대회에는 클럽의 **대국 삭제**가 없으므로 동기화된 세션에서 한 테이블을 삭제해 고치지 마세요. 이전 오류는 이후 어느 국을 재입력할지 심판과 합의합니다.

#### 6. 결과 승인과 계속 진행

전 테이블 종료 후 **승인 준비 완료**가 됩니다. 오류부터 해결하고 **세션 승인**을 확인합니다. 공개 설정에 따라 결과를 게시하고 다음 배정을 허용합니다. 승인 후에는 일반 대회 조작으로 해당 국들을 취소할 수 없습니다.

<GuideScreenshot name="tournament-approve" alt="전체 세션 승인 확인. 모든 테이블을 먼저 검토하세요. 대국 종료와 승인은 별도입니다." caption="전체 세션 승인 확인. 모든 테이블을 먼저 검토하세요. 대국 종료와 승인은 별도입니다." />

배정 → 확인 → 타이머 → 기록 → 검토·승인을 반복합니다. **이벤트 종료**는 전체 이벤트를 끝내므로 세션 사이에 사용하지 마세요.

<h3 id='predefined'>사전 지정 배정: 스크립트 준비</h3>

**대회 설정**에서 **자리를 미리 지정**을 켜고 저장합니다. 자동 방법 대신 **다음 배정**이 나타납니다.

1. 참가자를 등록하고 **선수 관리 → 로컬 ID**에서 고유 번호를 지정해 저장합니다. 이벤트 전용 번호이며 계정 System ID와 다릅니다.
2. **사전 지정 배정**을 열어 한 줄에 한 테이블, 로컬 ID를 하이픈으로 구분해 입력합니다. 빈 줄로 세션을 나눕니다. 테이블당 네 명, 삼마는 세 명이며 같은 세션에 한 선수를 중복 배치하지 마세요.
3. 새 스크립트는 **다음 세션 인덱스**를 1로 두고 **스크립트 갱신**을 누릅니다. 검증 오류를 모두 해결합니다.
4. **대국 관리**에서 **다음 배정**을 확인하고 테이블·바람 확인 후 타이머를 시작합니다. 인덱스는 타이머 시작 때 증가합니다. 승인 후 다음 블록을 생성합니다.

<GuideScreenshot name="predefined-script" alt="두 세션, 다음 인덱스와 오류 없음 표시. 숫자는 저장한 로컬 ID이며 System ID가 아닙니다." caption="두 세션, 다음 인덱스와 오류 없음 표시. 숫자는 저장한 로컬 ID이며 System ID가 아닙니다." />

각 세션에 네 명 테이블 두 개가 있는 예입니다.

```text
1-2-3-4
5-6-7-8

1-3-5-7
2-4-6-8
```

**스크립트 순서 바람**은 동–남–서–북을 유지합니다. 무작위·균형 바람은 테이블 그룹을 유지하면서 시작 바람을 바꿀 수 있습니다. 삼마는 한 줄 세 ID를 동–남–서 순서로 입력합니다. 블록이 다하면 먼저 추가하고 검증하세요. 인덱스는 다음 블록을 고르므로 함부로 바꾸지 마세요.
