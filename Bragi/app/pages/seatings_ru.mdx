## Как работают способы рассадки

Турнирную рассадку формируют на странице управления играми в <a href={env.urls.forseti}>панели управления</a>.
Полный порядок действий описан в <a href='/ru/forHosts#tournament'>инструкции организатору турнира</a>.
За столом должно быть четыре игрока, а в санме — три. Перед формированием проверьте включённых участников.

### Случайная рассадка

Игроки перемешиваются по столам без группировки по местам текущего рейтинга. Это доступный автоматический способ
для первой сессии, поскольку ему не нужны предыдущие результаты. В событии с заданным сценарием вместо этого
можно использовать сценарий с первой сессии.

Генератор пробует несколько случайных вариантов и сравнивает повторные встречи с предыдущими рассадками.
Он сохраняет лучший найденный вариант, затем назначает начальные ветры по настройкам события. Поэтому при наличии
истории игр результат не является полностью независимой случайной жеребьёвкой. Повторные соперники всё равно
возможны, особенно на поздних этапах турнира; этот способ не гарантирует ни новых соперников, ни близость
участников по рейтингу.

### Швейцарская рассадка

Учитывает текущий рейтинг и историю встреч. Старается посадить вместе близких по рейтингу игроков и уменьшить
число повторных соперников. Обе цели не всегда достижимы одновременно, поэтому повторная встреча сама по себе
не означает ошибку. Способ становится доступен после предыдущих игр; подтвердите их результаты перед следующей
сессией.

#### Как швейцарский алгоритм формирует столы

**Пересечение** означает, что два игрока уже играли за одним столом. Если они играли вместе дважды, это два
пересечения: учитывается количество предыдущих встреч, а не только сам факт знакомства соперников за столом.
Упрощённый порядок действий:

1. Берём текущую таблицу рейтинга и историю встреч. Выбираем игрока с наибольшим рейтингом из ещё не рассаженных
   и помещаем его за следующий стол.
2. Ищем доступного игрока с наибольшим рейтингом, который ещё не играл ни с кем из уже выбранных за этот стол.
3. Повторяем выбор, пока за столом не будет четыре игрока, а в санме — три. Каждый кандидат проверяется
   на встречи со всеми уже выбранными игроками, а не только с первым.
4. Исключаем выбранных участников из дальнейшего выбора и начинаем следующий стол с лучшего из оставшихся.
5. Если сделанный выбор не позволяет заполнить остальные столы при текущих ограничениях на пересечения,
   возвращаемся назад и пробуем другого кандидата. Первый подходящий вариант стола не обязательно станет окончательным.
6. Если обойтись без повторов уже не получается, разрешаем пересечения. Предпочтение получают кандидаты
   с меньшим числом прошлых встреч с выбранными участниками, а среди подходящих — с большим рейтингом.
7. Продолжаем, пока не будут рассажены все, затем назначаем начальные ветры согласно выбранному режиму.

Поиск имеет комбинаторную сложность: полный перебор всех рассадок становится непрактичным при росте числа игроков.
Генератор ограничивает объём поиска, ослабляя ограничения на пересечения по мере усложнения перебора.
Глобально оптимальная рассадка и абсолютно минимальное число повторных встреч не гарантируются.

Для последних столов остаётся меньше кандидатов, поэтому избежать повторов там может быть сложнее.
Реальная история встреч важнее одного лишь числа столов: количество столов, равное степени двойки, не гарантирует
отсутствия повторов, а другие количества столов тоже поддерживаются.

### Интервальная рассадка

Группирует игроков по местам текущего рейтинга с выбранным шагом. История встреч для предотвращения повторов
не используется. Способ становится доступен после предыдущих игр.

- Интервал **1**: места 1–2–3–4, затем 5–6–7–8.
- Интервал **2**: места 1–3–5–7, затем 2–4–6–8.
- Больший интервал сильнее разносит места рейтинга. Оставшиеся игроки образуют последующие столы.
- В санме за столом три игрока: например, интервал 1 начинается с 1–2–3, интервал 2 — с 1–3–5.

#### Как формируются интервальные группы и оставшиеся столы

Интервал — положительное целое число. Для четырёх игроков за столом интервал 3 формирует группы по три стола
из последовательных блоков по 12 участников рейтинга. Первый блок:

- Стол 1: места **1–4–7–10**.
- Стол 2: места **2–5–8–11**.
- Стол 3: места **3–6–9–12**.

Следующие три стола так же формируются из мест 13–24. Столы упорядочиваются по лучшему месту игрока за столом.
Таким образом, интервал разносит участников внутри каждого блока, а не распределяет всех участников поровну
между всеми столами турнира.

Если число столов не кратно выбранному интервалу, игроки из нижней части рейтинга, не вошедшие в полную
интервальную группу, рассаживаются с **интервалом 1**. Например, при 16 игроках и интервале 3 первые 12
образуют три стола выше, а места **13–14–15–16** составляют оставшийся стол. Если интервал больше общего
числа столов, такой порядок применяется ко всем столам.

В санме полная группа содержит число игроков, равное утроенному интервалу: при интервале 3 это девять
участников. Оставшиеся столы также заполняются соседними местами рейтинга. Ни основные группы, ни заполнение
остатка не учитывают прошлых соперников, поэтому на оставшихся столах могут чаще повторяться встречи.

### Заранее заданная рассадка

Включите заранее заданную рассадку в настройках турнира, назначьте и сохраните **Локальные идентификаторы** на странице
управления игроками, затем заполните сценарий в настройке предопределённой рассадки. Одна строка — один стол,
локальные ID разделяются дефисами; пустая строка отделяет следующую сессию. В строке четыре ID, а в санме — три.

Задайте индекс нужной следующей сессии, начиная с 1, обновите сценарий и устраните ошибки проверки.
На странице управления играми кнопка следующей рассадки сформирует этот блок. Индекс увеличивается при запуске
таймера. После подтверждения результатов сформируйте следующий блок. Если блоки закончились, сначала добавьте
и проверьте новые. См. <a href='/ru/forHosts#predefined'>пошаговую настройку и пример сценария</a>.

#### Сочетание сценария с автоматическими рассадками

Заранее заданная рассадка требует подготовки: сохраните соответствие игроков локальным ID и полный план столов
до формирования первой сессии. Автоматические способы, напротив, рассчитывают следующую рассадку по доступным
на этот момент зарегистрированным игрокам, рейтингу и истории встреч.

Если выключить заранее заданную рассадку, станут доступны автоматические способы; они используют существующие
результаты и историю встреч события. При последующем возврате к сценарию внимательно проверьте и сам сценарий,
и **Индекс следующей сессии**. Выбранный блок должен соответствовать сессии, которую вы действительно собираетесь
играть: смена режима сама не создаёт подходящий сценарий и не удаляет предыдущие игры. Готовьте такой переход
заранее, а не меняйте режим в ходе сессии.

### Состав столов и начальные ветры

Способ рассадки определяет состав столов. Настройка начальных ветров определяет места внутри стола:

- **Случайный выбор:** ветры назначаются случайно.
- **Сбалансированный выбор:** система старается назначать игроку ветры, на которых он играл реже.
- **По сценарию:** доступно для заранее заданной рассадки; используется порядок строки сценария,
  Восток–Юг–Запад–Север (Восток–Юг–Запад в санме).

Проверьте столы и ветры, когда рассадка готова. Если есть ошибка, сбросьте рассадку до запуска таймера.
Когда все заняли места, запуск таймера одновременно начинает игры всех столов.
