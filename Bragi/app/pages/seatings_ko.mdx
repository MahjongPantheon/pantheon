## 자리 배정 방식의 원리

<a href={env.urls.forseti}>관리 패널</a>의 **대국 관리**에서 생성합니다. 전체 절차는 <a href='/ko/forHosts#tournament'>대회 운영 안내</a>를 참고하세요. 테이블당 네 명, 삼마는 세 명이 필요합니다. 포함된 명단을 확인하세요. 그림은 영어 화면의 테스트 데이터입니다.

### 무작위 배정

순위별로 묶지 않고 섞어 테이블을 만듭니다. 이전 결과가 필요 없어 첫 세션부터 가능한 자동 방식입니다. 사전 지정 이벤트는 처음부터 스크립트를 사용할 수 있습니다.

여러 무작위 안을 시도해 이전 배정과의 재대결을 비교하고 찾은 최선의 안을 유지한 뒤 설정에 따라 시작 바람을 배분합니다. 이력이 있으면 완전히 제약 없는 추첨은 아닙니다. 특히 후반에는 반복이 가능하며 새 상대나 비슷한 순위를 보장하지 않습니다.

### 스위스식 배정

현재 순위와 대결 이력으로 비슷한 순위끼리 묶으면서 재대결을 줄이려 합니다. 두 목표를 동시에 만족하지 못할 수 있어 반복이 반드시 오류는 아닙니다. 이전 대국 후 사용 가능하며 다음 생성 전에 결과를 승인하세요.

#### 테이블을 구성하는 알고리즘

**대결**은 두 선수가 같은 테이블에서 한 번 플레이한 것입니다. 두 번 같이 했다면 두 번으로 세므로 만난 여부뿐 아니라 횟수를 봅니다.

1. 순위와 이력에서 아직 배정되지 않은 최고 순위 선수를 다음 테이블에 둡니다.
2. 그 테이블의 누구와도 만난 적 없는 후보 중 가장 높은 순위를 찾습니다.
3. 네 명(삼마 세 명)까지 반복합니다. 첫 선수뿐 아니라 선택된 모두와 비교합니다.
4. 해당 선수를 제외하고 남은 최고 순위로 다음 테이블을 시작합니다.
5. 선택 때문에 현재 대결 제한으로 나머지 테이블을 완성할 수 없으면 되돌아가 다른 후보를 시도합니다. 처음 유망한 테이블이 최종안일 필요는 없습니다.
6. 반복을 피할 수 없으면 재대결을 허용합니다. 선택한 선수들과 과거 대결이 적은 후보를 우선하고 그중 순위가 높은 선수를 고릅니다.
7. 모두 배정한 후 선택한 방식으로 시작 바람을 지정합니다.

조합 탐색이므로 인원이 늘면 모든 안을 검사하기 어렵습니다. 탐색 비용이 커질수록 대결 제약을 완화해 작업량을 제한합니다. 전역 최적이나 절대 최소 반복 횟수는 보장하지 않습니다.

뒤 테이블은 선택지가 적어 반복을 피하기 어려울 수 있습니다. 테이블 수보다 실제 이력이 중요합니다. 테이블 수가 2의 거듭제곱이어도 무반복을 보장하지 않으며 다른 수 역시 지원합니다.

### 간격 배정

현재 순위의 지정 간격으로 묶으며 대결 이력으로 반복을 피하지 않습니다. 이전 대국이 있어야 사용할 수 있습니다.

- 간격 **1**: 1–2–3–4, 다음 5–6–7–8.
- 간격 **2**: 1–3–5–7, 다음 2–4–6–8.
- 큰 간격은 그룹 내 순위 차이를 넓히고 남은 선수는 뒤 테이블에 갑니다.
- 삼마는 세 명으로, 간격 1은 1–2–3, 간격 2는 1–3–5 등입니다.

#### 간격 그룹과 남는 테이블

간격은 양의 정수입니다. 네 명 테이블의 간격 3은 순위 열두 명씩 세 테이블을 만듭니다.

- 테이블 1: **1–4–7–10**.
- 테이블 2: **2–5–8–11**.
- 테이블 3: **3–6–9–12**.

다음 그룹은 13–24위로 반복합니다. 테이블은 각 최고 순위 선수 기준으로 정렬됩니다. 블록 안에서 분산하는 것이지 전체 인원을 모든 테이블에 고르게 나누는 방식은 아닙니다.

테이블 수가 간격으로 나누어떨어지지 않으면 완전한 그룹에 못 들어간 하위 선수는 **간격 1**로 배정합니다. 16명·간격 3이면 앞 열두 명은 위 세 테이블, **13–14–15–16**은 마지막 테이블입니다. 간격이 총 테이블 수보다 크면 모든 테이블에 이 대체 방식이 적용됩니다.

삼마의 완전 그룹은 간격의 세 배 인원이며 간격 3이면 아홉 명입니다. 남는 테이블도 인접 순위로 채웁니다. 일반 그룹과 대체 그룹 모두 이전 상대를 피하지 않아 남은 테이블에 반복이 몰릴 수 있습니다.

### 사전 지정 배정

**자리를 미리 지정**을 켜고 **선수 관리**에서 **로컬 ID**를 저장한 뒤 **사전 지정 배정**에 입력합니다. 한 줄은 로컬 ID를 하이픈으로 구분한 테이블이며 빈 줄이 다음 세션입니다. 네 ID, 삼마는 세 ID를 사용합니다.

<GuideScreenshot name="predefined-ids" alt="이벤트별로 저장한 로컬 선수 번호. 스크립트는 계정 System ID가 아닌 이 번호를 씁니다." caption="이벤트별로 저장한 로컬 선수 번호. 스크립트는 계정 System ID가 아닌 이 번호를 씁니다." />

**다음 세션 인덱스**를 원하는 블록(1부터)으로 설정해 갱신하고 검증 오류를 해결합니다. **다음 배정**으로 그 블록을 생성합니다. 타이머 시작 시 인덱스가 증가하고 결과 승인 후 다음 블록을 생성합니다. 블록이 없으면 먼저 추가·검증하세요. <a href='/ko/forHosts#predefined'>절차와 예시</a>도 참고하세요.

#### 스크립트와 자동 방식 전환

첫 생성 전에 선수와 로컬 ID의 대응 및 전체 계획을 저장해야 합니다. 자동 방식은 그 시점의 등록 선수, 순위와 이력으로 다음 배정을 계산합니다.

**자리를 미리 지정**을 끄면 기존 결과와 이력을 사용하는 자동 방식이 열립니다. 나중에 돌아올 때는 스크립트와 **다음 세션 인덱스**를 확인해 실제 진행할 블록과 맞추세요. 모드 변경은 맞는 스크립트를 만들거나 이전 대국을 지우지 않습니다. 세션 도중이 아니라 미리 전환을 준비하세요.

### 테이블 그룹과 시작 바람

배정 방식은 테이블 그룹을 정하고 **바람 배분 모드**는 그룹 내 시작 좌석을 정합니다.

- **무작위:** 각 테이블에서 바람을 임의 지정합니다.
- **균형:** 각 선수가 이전에 적게 맡은 바람을 우선합니다.
- **스크립트 순서:** 사전 지정의 줄 순서인 동–남–서–북, 삼마는 동–남–서를 따릅니다.

**배정 준비 완료**에서 테이블과 바람을 확인하세요. 시작 전에 **배정 초기화**로 오류를 버릴 수 있습니다. 모두 앉으면 **타이머 시작**으로 전체 테이블을 동시에 시작합니다.
