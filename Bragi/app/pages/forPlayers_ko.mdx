## 모바일 도우미 사용 방법

휴대전화에서 <a href={env.urls.tyr}>모바일 도우미</a>를 엽니다. 활성화된 계정과 이벤트 등록이 필요합니다. <Link to='/getStarted'>시작하기와 계정 도움말</Link>을 참고하세요.

목차: [이벤트](#event), [클럽](#club), [대회](#tournament), [기록](#recording), [이력과 수정](#corrections). 스크린샷은 영어 화면과 가상 선수이며 누르면 확대됩니다.

<h3 id='event'>1. 로그인하고 이벤트 선택</h3>

이메일과 비밀번호로 로그인해 클럽 순위표나 대회를 선택합니다. 목록이 비었거나 이벤트가 없으면 주최자에게 등록을 확인받으세요. 가입만으로 참가 등록되지는 않습니다.

<GuideScreenshot name="mobile-events" alt="클럽과 대회 목록. 실제 참가하는 이벤트를 선택하세요." caption="클럽과 대회 목록. 실제 참가하는 이벤트를 선택하세요." mobile />

홈은 이벤트 이름과 가능한 작업을 표시합니다. 진행 중인 대국이 있으면 테이블로 바로 이동할 수 있으며 홈 버튼으로 메뉴에 돌아갑니다.

<GuideScreenshot name="mobile-home" alt="새 대국과 통계가 있는 클럽 홈. 입력 전에 이벤트 이름을 확인하세요." caption="새 대국과 통계가 있는 클럽 홈. 입력 전에 이벤트 이름을 확인하세요." mobile />

톱니바퀴에서 언어, 테마, 개인 영역, 이벤트 변경과 로그아웃을 이용합니다. **단일 기기 모드**는 휴대전화 하나로 전체 테이블을 기록할 때 편리하며 각자가 기기를 조작할 필요가 없습니다.

<GuideScreenshot name="mobile-settings" alt="언어, 테마, 이벤트와 단일 기기 설정. 계정과 비밀번호는 계정 안내를 참고하세요." caption="언어, 테마, 이벤트와 단일 기기 설정. 계정과 비밀번호는 계정 안내를 참고하세요." mobile />

<h3 id='club'>2. 클럽 대국 시작</h3>

1. 홈에서 **새 대국**을 누릅니다.
2. 등록된 선수를 **동–남–서–북**, 삼마는 **동–남–서** 순으로 선택합니다. 필요하면 선택을 지우고 다시 합니다.
3. 시작 자리를 무작위로 정하려면 섞기 버튼을 누르고 함께 순서를 확인합니다.
4. 이름과 바람을 확인하고 시작합니다. 한 사람만 생성하면 다른 참가자는 새로고침으로 같은 테이블에 들어갑니다.

<GuideScreenshot name="mobile-new-game" alt="네 선수가 선택된 새 대국의 섞기와 시작 버튼. 참가자와 시작 바람을 확인하세요." caption="네 선수가 선택된 새 대국의 섞기와 시작 버튼. 참가자와 시작 바람을 확인하세요." mobile />

클럽은 공통 타이머가 없습니다. 동풍전·반장, 연장, 목표 점수, 토비 등 이벤트 규칙에 따라 끝납니다. 사람을 잘못 골랐다면 기록 전에 관리자에게 빈 대국 삭제를 요청하세요.

<h3 id='tournament'>3. 대회 테이블 참가</h3>

관리자가 자리를 생성합니다. **새 대국**으로 대회 테이블을 만들지 마세요. 자리가 준비되면 테이블 번호와 시작 바람을 확인하고 이동해 참가자를 대조합니다.

<GuideScreenshot name="mobile-tournament-ready" alt="타이머 시작 전 테이블 배정. 지정된 자리에 앉아 시작 신호를 기다리세요." caption="타이머 시작 전 테이블 배정. 지정된 자리에 앉아 시작 신호를 기다리세요." mobile />

관리자가 전체 테이블과 타이머를 함께 시작하며 도우미는 남은 시간을 표시합니다. 시간과 종료 정책은 이벤트마다 다릅니다. 현재 국 종료, 한 국 추가, 자연 종료 등이 있으므로 안내와 상태를 따르세요. 모든 대회에 적용되는 75분 규칙은 없습니다.

<GuideScreenshot name="mobile-tournament-timer" alt="진행 중인 대회와 카운트다운. 연장 시간도 주최자가 관리합니다." caption="진행 중인 대회와 카운트다운. 연장 시간도 주최자가 관리합니다." mobile />

테이블 종료 후 전체 세션 승인을 기다리세요. 오류는 승인 전에 알립니다. 결과는 공개 설정에 따라 표시되고 다음 자리는 다음 배정 생성 후 나타납니다.

<h3 id='recording'>4. 한 국 기록</h3>

한 사람이 입력하고 모두 확인합니다. 상태는 모든 기기에서 공유하므로 같은 국을 여러 번 입력하지 마세요.

<GuideScreenshot name="mobile-table" alt="점수, 바람과 추가 버튼이 있는 테이블. 더하기로 결과 메뉴를 엽니다." caption="점수, 바람과 추가 버튼이 있는 테이블. 더하기로 결과 메뉴를 엽니다." mobile />

1. **+**를 누르고 규칙에 따라 **론**, **쯔모**, **유국**, **도중유국**, **쵼보**, **나가시만관**을 선택합니다. 더블·트리플 론은 론 한 번에 모든 승자를 선택하며 별도 국으로 나누지 않습니다.

<GuideScreenshot name="mobile-outcome" alt="론, 쯔모, 유국과 쵼보 등의 결과 메뉴. 실제 종료 결과를 고르세요." caption="론, 쯔모, 유국과 쵼보 등의 결과 메뉴. 실제 종료 결과를 고르세요." mobile />

2. 론은 승자와 방총자, 쯔모는 승자, 유국은 텐파이 선수, 쵼보는 벌칙 대상을 선택합니다. 이 화면에서 해당 국의 리치 선언자도 모두 표시한 뒤 진행합니다.

<GuideScreenshot name="mobile-players" alt="승자, 방총자와 리치 상태 선택. 리치는 역 선택 전에 표시합니다." caption="승자, 방총자와 리치 상태 선택. 리치는 역 선택 전에 표시합니다." mobile />

3. 승자마다 역을 선택합니다. **후로한 손패**를 선택하지 않으면 멘젠으로 취급합니다. 여러 승자는 각 탭을 확인하세요. 가능한 역과 조합은 규칙에 따라 다릅니다. 상충 항목이 비활성화되어도 선수가 직접 검증해야 합니다.
4. 전체 도라 수와 부수를 설정합니다. 일부 부수는 역에 의해 고정되거나 제한됩니다. 도라는 유효한 역을 대신하지 않습니다. 책임지불(파오)을 요청하면 지정하세요.

<GuideScreenshot name="mobile-hand" alt="역, 도라와 부수 편집. 멘젠·후로 여부와 모든 승자를 확인하세요." caption="역, 도라와 부수 편집. 멘젠·후로 여부와 모든 승자를 확인하세요." mobile />

5. 미리보기에서 점수 변화를 모두에게 보여주고 이견을 해결합니다. 뒤로 가서 수정하고 전원 동의 후 체크 버튼으로 제출합니다.

<GuideScreenshot name="mobile-preview" alt="제출 전 점수 변화 미리보기. 확인 버튼을 눌러야 저장됩니다." caption="제출 전 점수 변화 미리보기. 확인 버튼을 눌러야 저장됩니다." mobile />

제출 후 점수와 국을 확인하세요. 연결 문제 시 먼저 새로고침하고 로그에 저장되었는지 확인한 다음 재입력하세요.

<h3 id='corrections'>5. 이력 확인과 수정</h3>

테이블의 로그 버튼으로 기록을 보고 행을 눌러 상세 내용을 엽니다. 선수 점수를 누르면 점수 차이를 볼 수 있습니다.

<GuideScreenshot name="mobile-log" alt="한 국의 상세 내용을 펼친 대국 로그. 수정할 국을 먼저 합의하세요." caption="한 국의 상세 내용을 펼친 대국 로그. 수정할 국을 먼저 합의하세요." mobile />

제출 오류는 심판이나 관리자를 부르세요. 선수가 직접 취소할 수 없습니다. 심판이 마지막 국을 취소하면 올바르게 입력합니다. 이전 국 수정은 이후 국도 취소하고 다시 기록해야 하므로 내용을 먼저 확인하세요.

완료된 클럽 대국은 누군가 다음 대국을 시작하기 전에 연락하세요. 이후 대국이 있으면 재개가 막힐 수 있습니다. 대회는 세션 승인 전에 신고하세요. 타이머가 0이 되는 것과 승인은 별개입니다.

홈의 **통계** 또는 <a href={env.urls.sigrun}>순위표와 통계</a>에서 순위, 완료 대국과 선수 통계를 볼 수 있으며 공개 설정이 적용됩니다.
