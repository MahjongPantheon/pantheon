## 不具合・問題の報告

- <a href='https://github.com/MahjongPantheon/pantheon/issues' target='_blank'>Pantheon の GitHub リポジトリの Issues ページ</a>を開きます。
- **New issue** をクリックします。GitHub へのログインが必要な場合があります。
- **Title** と **Description** に問題や提案を記入します。できれば英語でお願いします。
- ファイルやスクリーンショットは説明欄にドラッグして添付できます。
- **Submit new issue** で送信します。

進捗は<a href='https://github.com/MahjongPantheon/pantheon/issues'>Issues ページ</a>で確認できます。

### 開発チームに質問がある、または GitHub アカウントを作りたくない場合

サポートチャットをご利用ください。

- <a href='https://t.me/pantheon_support'>Telegram（主にロシア語）</a>
- <a href='https://discord.gg/U5qBkexfEQ'>Discord（英語）</a>
