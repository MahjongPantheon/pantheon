## Fehler und Probleme melden

- Öffnen Sie die <a href='https://github.com/MahjongPantheon/pantheon/issues' target='_blank'>Issues im GitHub-Repository von Pantheon</a>.
- Klicken Sie auf **New issue**. Gegebenenfalls müssen Sie sich bei GitHub anmelden.
- Füllen Sie **Title** und **Description** aus. Beschreiben Sie Ihr Problem oder Ihre Idee möglichst auf Englisch.
- Ziehen Sie Dateien oder Screenshots in das Beschreibungsfeld, um sie anzuhängen.
- Klicken Sie zum Abschluss auf **Submit new issue**.

Den Bearbeitungsstand finden Sie jederzeit auf der <a href='https://github.com/MahjongPantheon/pantheon/issues'>Issues-Seite</a>.
