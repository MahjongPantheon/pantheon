## クラブ・大会の管理

<a href={env.urls.forseti}>管理画面</a>へログインし、**自分のイベント**から対象を選びます。**操作**メニューまたは左の一覧から**プレイヤー管理**、**対局管理**、**設定**を開きます。表示されない場合は管理者に**権限管理**でアクセスを付与してもらいます。参加しているだけでは管理権限はありません。

目次：[クラブ](#club)、[大会](#tournament)、[事前指定席順](#predefined)。アカウントと形式は<Link to='/getStarted'>はじめに</Link>をご覧ください。画像は英語画面と架空の TEST イベントで、クリックすると拡大できます。

<h3 id='club'>クラブ：参加者登録と対局管理</h3>

#### 1. イベントを作成・選択する

**新しいイベントを作成**から**ローカルランキング**を選び、名称、基本ルール、タイムゾーンと他の設定を確認して保存します。練習用は名称に TEST を付けます。クラブイベントは何度もの集まりにわたり継続でき、卓は独立して開始・終了します。

#### 2. プレイヤーを追加する

1. 先に<a href='/jp/getStarted#sign-up'>アカウントを作成・有効化</a>してもらいます。
2. **プレイヤー管理**で名前、または `#` に続けて System ID を検索します。
3. 正しい結果を選び、同名の場合は ID を確認します。
4. すぐ名簿に追加され、アシスタントでイベントを選べます。全員分繰り返し、見つからなければプロフィールの名前や System ID を確認します。

<GuideScreenshot name="club-players" alt="クラブの検索と登録済み名簿。既存アカウントをイベントへ追加する操作で、アカウント作成とは別です。" caption="クラブの検索と登録済み名簿。既存アカウントをイベントへ追加する操作で、アカウント作成とは別です。" height={960} />

運用中も追加できます。誤登録は削除アイコンが使える場合に取り除けますが、対局は取り消されません。管理権限は**権限管理**で別途設定します。

#### 3. プレイヤーが対局を開始する

アシスタントの**新規対局**で登録済みの参加者を東–南–西–北（三麻は東–南–西）に選び、必要ならシャッフルして開始します。共通タイマーや自動の大会席順はありません。<a href='/jp/forPlayers#club'>プレイヤー向けガイド</a>をご覧ください。

#### 4. 間違って始めた対局を取り消す

1. **対局管理**で参加者から卓を特定します。
2. 一局も記録していなければ**対局を削除**して確認します。空の対局全体が削除されます。
3. アシスタントを更新し、正しい参加者と席順で始め直してもらいます。

<GuideScreenshot name="club-remove-game" alt="未記録のクラブ対局にある削除ボタン。最初の局を記録すると使用できなくなります。" caption="未記録のクラブ対局にある削除ボタン。最初の局を記録すると使用できなくなります。" />

記録後は**直前の局を取り消す（Cancel round）**に変わります。内容を確認して取り消し、正しい結果を入力します。古い誤りは後の局を新しい順に取り消し、実際の順に再入力するため、先に記録を合意してください。全局を取り消すと空の対局を削除できます。

<GuideScreenshot name="club-cancel-round" alt="直前の局の取消確認。対局全体ではなく最後の一局だけを取り消します。" caption="直前の局の取消確認。対局全体ではなく最後の一局だけを取り消します。" />

終了済みクラブ対局の**最後の局と結果を取り消す**は、直前の局と公開結果を消して再開します。サーバーが許可する場合のみで、参加者が次の対局を始めると使えない場合があります。次の開始前に訂正してください。

<h3 id='tournament'>大会：名簿から結果承認まで</h3>

#### 1. イベントと時間を設定する

**大会**を作成・選択し、ルールとタイムゾーンを設定します。**大会設定**で**セッション時間（分）**と**終了方針**を確認して保存します。

- 時間で中断せず、対局が終わるまで続行する。
- 時間切れ後、現在の局を終えて終了する。
- 現在の局とさらに一局を行って終了する。

<GuideScreenshot name="tournament-settings" alt="時間、終了方針、事前指定席順、風の設定。時間と終了条件を事前に案内します。" caption="時間、終了方針、事前指定席順、風の設定。時間と終了条件を事前に案内します。" height={1081} />

#### 2. 開始前に全員を登録する

**プレイヤー管理**で名前か `#SystemID` を検索して追加します。初回の席順作成前に名簿を完成してください。大会セッションの作成時点で追加・削除が制限され、タイマー開始前でも変更できません。

自動席順の対象人数は**四**の倍数、三麻は**三**の倍数が必要です。状態が許すとき、椅子アイコンで次の席順への参加・除外を指定します。打たない審判などは除外します。除外しても登録は残ります。対象人数を正しく保ってください。

<GuideScreenshot name="tournament-players" alt="椅子アイコンのある大会名簿。席順生成ごとに対象者を確認します。" caption="椅子アイコンのある大会名簿。席順生成ごとに対象者を確認します。" height={960} />

代走は名前横の交代機能で、まだイベントに登録されていない人を選びます。代走の集計は設定に従います。本人が戻ったら結果承認前に代走を解除します。

#### 3. 席順を作成する

**対局管理**の**準備未完了**は人数の修正が必要です。**未開始**なら方法を選び確認します。

- **ランダム：** 初回から使用可。順位でまとめず、再対戦を減らそうとしますが新しい相手は保証しません。
- **スイス式：** 対局履歴ができてから使用可。順位と履歴から近い順位の相手を探し、再対戦を減らします。重複はあり得ます。
- **間隔指定：** 対局後に使用可。間隔1は1–2–3–4、5–6–7–8、間隔2は1–3–5–7、2–4–6–8です。
- **次の席順：** 事前指定イベント用です。[下記](#predefined)をご覧ください。

<GuideScreenshot name="tournament-seating" alt="初回の自動生成はランダムを使用。スイス式と間隔指定には過去の対局が必要です。" caption="初回の自動生成はランダムを使用。スイス式と間隔指定には過去の対局が必要です。" />

<GuideScreenshot name="tournament-interval" alt="間隔の確認画面。前回の結果承認後に次の方法を選びます。" caption="間隔の確認画面。前回の結果承認後に次の方法を選びます。" />

**席順作成中**は待機し、**席順準備完了**で卓と起家時の風を確認します。プレイヤーはアシスタントで卓を確認でき、ランキングサービスの**タイマーと席順**を共用画面に表示することもできます。誤りは開始前に**席順をリセット**し、作り直します。

<GuideScreenshot name="tournament-ready" alt="完成した卓、席順リセット、タイマー開始。着席はできますが、まだ開始していません。" caption="完成した卓、席順リセット、タイマー開始。着席はできますが、まだ開始していません。" />

#### 4. タイマーを開始・延長する

全員が座ったら**タイマー開始**を確認し、明確な開始合図も出します。全卓同時に始まり、**セッション開始済み**となります。

全体操作の**時間を追加**は全卓へ1、2、3、4、5、7分を追加します。個別卓内の同じ操作はその卓だけを延長し、審判対応などに使えます。確認前に対象範囲を確認してください。現在の画面には延長があり、一時停止・リセットボタンはありません。

<GuideScreenshot name="tournament-timer" alt="全卓対象と明記された延長ダイアログ。個別の遅れには卓内の延長を使用します。" caption="全卓対象と明記された延長ダイアログ。個別の遅れには卓内の延長を使用します。" />

時間切れ後は設定済みの終了方針に従います。ゼロになっても結果は自動承認されません。

#### 5. 記録を訂正する

対象卓で**直前の局を取り消す**を確認し、プレイヤーに更新して正しい結果を入れてもらいます。取り消せるのは直前の一局のみです。卓の終了後でも承認前なら操作できます。

<GuideScreenshot name="tournament-cancel-round" alt="大会卓の局取消確認。同期した大会セッション全体は続行します。" caption="大会卓の局取消確認。同期した大会セッション全体は続行します。" />

開始前の席順は**席順をリセット**で破棄します。大会卓にはクラブの**対局を削除**はありません。一卓を同期セッションから削除して修正しないでください。古い誤りは、再入力すべき後続局を審判と確認します。

#### 6. 結果を承認して次へ進む

全卓終了で**承認可能**になります。訂正を先に済ませ、**セッションを承認**を押して確認します。公開設定に応じて結果が公開され、次の席順を作れます。承認後は通常の大会操作では局を取り消せません。

<GuideScreenshot name="tournament-approve" alt="全セッションの承認確認。全卓をチェックしてください。終局と結果承認は別の段階です。" caption="全セッションの承認確認。全卓をチェックしてください。終局と結果承認は別の段階です。" />

席順 → 確認 → タイマー → 記録 → 確認と承認を繰り返します。**イベント終了**は全体を終了するため、セッション間で使わないでください。

<h3 id='predefined'>事前指定席順：スクリプトを準備する</h3>

**大会設定**で**席順を事前に指定**を有効にして保存します。自動方式の代わりに**次の席順**が表示されます。

1. 参加者を登録し、**プレイヤー管理 → ローカル ID**で重複しない番号を割り当てて保存します。イベント専用で、アカウントの System ID とは異なります。
2. 左の**事前指定席順**を開き、一行に一卓、ローカル ID をハイフンで区切って入力します。空行でセッションを分けます。一卓四人、三麻三人で、同じセッション内に重複はできません。
3. 新規スクリプトでは**次のセッション番号**を1にして**スクリプト更新**を押し、すべての検証エラーを修正します。
4. **対局管理**の**次の席順**を確認し、卓と風を確認してタイマーを開始します。番号はタイマー開始時に進みます。結果承認後に次のブロックを生成します。

<GuideScreenshot name="predefined-script" alt="二セッションのスクリプト、次の番号、エラーなしの表示。数字は保存済みのローカル ID です。" caption="二セッションのスクリプト、次の番号、エラーなしの表示。数字は保存済みのローカル ID です。" />

各セッションに四人卓が二つある例：

```text
1-2-3-4
5-6-7-8

1-3-5-7
2-4-6-8
```

**スクリプト順の風**なら東–南–西–北を維持します。ランダム・均等化は卓の組合せを維持し、風を変更する場合があります。三麻は三つの ID を東–南–西順にします。残りブロックがなければ先に追加・検証してください。番号は次のブロックを指定するため、不用意に変えないでください。
