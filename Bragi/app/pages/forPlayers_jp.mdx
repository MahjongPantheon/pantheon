## モバイルアシスタントの使い方

スマートフォンで<a href={env.urls.tyr}>モバイルアシスタント</a>を開きます。有効化済みのアカウントとイベント参加登録が必要です。<Link to='/getStarted'>はじめに・アカウントのヘルプ</Link>もご覧ください。

目次：[イベント](#event)、[クラブ](#club)、[大会](#tournament)、[局の記録](#recording)、[履歴と訂正](#corrections)。画像は英語画面と架空のプレイヤーです。タップで拡大できます。

<h3 id='event'>1. ログインしてイベントを選ぶ</h3>

メールとパスワードでログインし、クラブランキングまたは大会を選びます。空欄や目的のイベントがない場合は参加登録を確認してもらってください。アカウント作成だけでは参加できません。

<GuideScreenshot name="mobile-events" alt="クラブと大会のイベント一覧。参加するイベントを選びます。" caption="クラブと大会のイベント一覧。参加するイベントを選びます。" mobile />

ホームにはイベント名と操作が表示されます。進行中の対局があれば卓へ直接移動する場合があります。ホームボタンでメニューに戻れます。

<GuideScreenshot name="mobile-home" alt="新規対局と統計のあるクラブのホーム。入力前にイベント名を確認します。" caption="新規対局と統計のあるクラブのホーム。入力前にイベント名を確認します。" mobile />

歯車から言語、テーマ、個人ページ、イベント切替、ログアウトを操作します。**単一端末モード**は一台で全員分を記録するときに適し、各自のスマートフォン操作を必要としません。

<GuideScreenshot name="mobile-settings" alt="言語、テーマ、イベント、単一端末モードの設定。アカウントやパスワードは専用ガイドをご覧ください。" caption="言語、テーマ、イベント、単一端末モードの設定。アカウントやパスワードは専用ガイドをご覧ください。" mobile />

<h3 id='club'>2. クラブの対局を開始する</h3>

1. ホームで**新規対局**を押します。
2. 登録済みプレイヤーを起家時の**東–南–西–北**順（三麻は**東–南–西**）に選びます。必要なら選択をクリアします。
3. ランダムにしたい場合はシャッフルし、全員で順番を確認します。
4. 名前と風を確認して開始します。一人が作成すれば、他の人は更新して同じ卓に入れます。

<GuideScreenshot name="mobile-new-game" alt="四人を選択した新規対局。シャッフル・開始前に参加者と起家時の風を確認します。" caption="四人を選択した新規対局。シャッフル・開始前に参加者と起家時の風を確認します。" mobile />

クラブに共通タイマーはありません。東風戦・半荘、連荘、目標点、飛びなどイベントのルールに従って終了します。参加者を間違えたら、記録前に管理者へ空の対局の削除を依頼してください。

<h3 id='tournament'>3. 大会の卓に入る</h3>

席順は管理者が作成します。**新規対局**で大会卓を作らないでください。席順が出たら卓番号と起家時の風を確認し、卓で参加者を照合します。

<GuideScreenshot name="mobile-tournament-ready" alt="タイマー開始前の卓と席の割り当て。着席して開始合図を待ちます。" caption="タイマー開始前の卓と席の割り当て。着席して開始合図を待ちます。" mobile />

管理者がタイマーと全卓を同時に開始し、アシスタントに残り時間が出ます。時間と終了方針はイベントごとに異なり、現在の局まで、さらに一局、または自然終了までの場合があります。案内と画面に従ってください。すべての大会が75分とは限りません。

<GuideScreenshot name="mobile-tournament-timer" alt="大会中のカウントダウン。時間延長も主催者が操作します。" caption="大会中のカウントダウン。時間延長も主催者が操作します。" mobile />

卓が終わったら全セッションの承認を待ちます。誤りは承認前に報告してください。結果は公開設定に従い、次の卓は次の席順生成後に表示されます。

<h3 id='recording'>4. 一局を記録する</h3>

一人が入力し、全員で確認します。状態は全端末で共有されるため、同じ局を複数回入力しないでください。

<GuideScreenshot name="mobile-table" alt="点数・風・追加ボタンのある卓画面。プラスで結果メニューを開きます。" caption="点数・風・追加ボタンのある卓画面。プラスで結果メニューを開きます。" mobile />

1. **+** から、ルールで使用可能な**ロン**、**ツモ**、**荒牌流局**、**途中流局**、**チョンボ**、**流し満貫**を選びます。ダブロン・トリプルロンはロンを選んで全和了者を指定し、別々の局にしません。

<GuideScreenshot name="mobile-outcome" alt="ロン、ツモ、流局、チョンボなどの結果選択。実際の終了理由を選びます。" caption="ロン、ツモ、流局、チョンボなどの結果選択。実際の終了理由を選びます。" mobile />

2. ロンは和了者と放銃者、ツモは和了者、荒牌流局は聴牌者、チョンボは罰則対象を選びます。この画面で当局にリーチした全員も指定してから進みます。

<GuideScreenshot name="mobile-players" alt="和了・放銃・リーチの状態指定。リーチは役の選択より前に入力します。" caption="和了・放銃・リーチの状態指定。リーチは役の選択より前に入力します。" mobile />

3. 和了者ごとに役を選びます。**副露した手牌**を選ばない限り門前扱いです。複数和了は各タブを確認します。役と組合せはルール次第で、矛盾する選択肢が無効でもプレイヤー自身の確認が必要です。
4. ドラの合計と符を指定します。役により符が固定・制限される場合があります。ドラは役の代わりにはなりません。責任払い（包）の指定が出たら入力します。

<GuideScreenshot name="mobile-hand" alt="役、ドラ、符の編集。門前・副露と各和了者の内容を確認します。" caption="役、ドラ、符の編集。門前・副露と各和了者の内容を確認します。" mobile />

5. プレビューで点数移動を全員に見せ、相違を解消します。戻るで修正し、全員が合意してからチェックボタンで送信します。

<GuideScreenshot name="mobile-preview" alt="送信前の点数移動プレビュー。確認ボタンで初めて記録されます。" caption="送信前の点数移動プレビュー。確認ボタンで初めて記録されます。" mobile />

送信後に点数と局を確認します。通信エラー時は更新し、ログに登録済みか確認してから再入力してください。

<h3 id='corrections'>5. 履歴の確認と訂正</h3>

卓のログボタンで各局を表示し、行をタップすると詳細が開きます。プレイヤーの点数をタップすると点差を確認できます。

<GuideScreenshot name="mobile-log" alt="詳細を開いた対局ログ。訂正する局を全員で確認します。" caption="詳細を開いた対局ログ。訂正する局を全員で確認します。" mobile />

送信済みの誤りは審判や管理者を呼んでください。プレイヤー自身では取り消せません。審判が直前の局を取り消し、正しい結果を再入力します。古い局の訂正には後の局も取り消して再入力する必要があるため、先に記録を確認します。

クラブの終了済み対局は、誰かが次の対局を始める前に連絡してください。後の対局があると再開できない場合があります。大会ではセッション承認前に報告します。タイマーがゼロになっても承認とは別です。

ホームの**統計**または<a href={env.urls.sigrun}>ランキングと統計</a>で順位、終了対局、個人統計を見られます。表示範囲は公開設定によります。
