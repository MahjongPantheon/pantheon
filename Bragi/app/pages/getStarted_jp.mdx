## はじめに・アカウントのヘルプ

<a href={env.urls.tyr}>モバイルアシスタント</a>で対局を記録し、<a href={env.urls.sigrun}>ランキングと統計</a>で結果を確認し、<a href={env.urls.forseti}>プロフィール・管理画面</a>でアカウントやイベントを管理します。すべて同じアカウントを使用します。

目次：[イベントの種類](#event-modes)、[アカウント作成](#sign-up)、[参加登録](#registration)、[プロフィール](#profile)、[パスワード](#password)、[よくある質問](#questions)。画像は英語画面と架空のプレイヤー、TEST イベントを使用しています。クリックすると原寸で開きます。

<h3 id='event-modes'>どのイベント形式を選べばよいですか？</h3>

**イベント（event）**には専用の参加者一覧、ルール、ランキングがあります。**セッション（session）**は通常一卓の対局を指しますが、大会管理では同時進行する全卓を指す場合もあります。英語の操作画面では一局を **round** または **hand** と呼びます。

- **ローカルランキング（クラブ）：** プレイヤー自身が対戦相手と起家時の席順を選び、対局を開始して各局を記録します。卓は独立して進行し、共通タイマーはありません。運用中も管理者がプレイヤーを追加できます。
- **大会：** 管理者が参加者と席順を準備し、タイマーで全卓を開始、終了したセッションをまとめて承認します。ランダム、スイス式、間隔指定、事前指定の席順が使えます。
- **オンラインイベント：** 対応する外部プラットフォームや牌譜から結果を取り込みます。必要なサイトとアカウントは主催者に確認してください。実卓での記録とは手順が異なります。

<h3 id='sign-up'>アカウントを作成するには？</h3>

1. <a href={`${env.urls.forseti}/profile/signup`}>新規アカウント登録</a>を開きます。
2. 受信可能なメール、プレイヤー名、安全なパスワードを入力します。主催者が見つけられるよう、分かりやすい姓名を使用してください。
3. プライバシーポリシーを読み、同意して**新規アカウント登録**を押します。
4. 確認メールのリンクを開き、ログインします。
5. <a href={`${env.urls.forseti}/profile/manage`}>プロフィール</a>を記入し、主催者にアカウントの準備ができたことを伝えます。

<GuideScreenshot name="account-signup" alt="メール、名前、パスワード、個人情報への同意を入力する登録画面。一つのアカウントで複数のイベントに参加できます。" caption="メール、名前、パスワード、個人情報への同意を入力する登録画面。一つのアカウントで複数のイベントに参加できます。" />

メールが来なければ迷惑メールとアドレスを確認し、解決しなければ管理者に連絡してください。既存アカウントがあればパスワードを再設定します。重複登録は対局履歴を分散させます。大会直前は主催者が対応する時間を取れない場合があるため、余裕を持って作成してください。

<h3 id='registration'>クラブや大会に参加するには？</h3>

**アカウント作成は Pantheon への登録、参加登録はそのアカウントを特定のイベントに追加する操作です。** 作成だけでは大会やクラブの名簿に入りません。

プレイヤー名またはプロフィールの **System ID** を主催者へ伝えます。主催者が**プレイヤー管理**で追加した後、アシスタントにログインしてイベントを選びます。主催者が別途案内する申込・支払手続きも行ってください。

<h3 id='profile'>プロフィールを管理するには？</h3>

1. <a href={env.urls.forseti}>プロフィール・管理画面</a>にログインし、<a href={`${env.urls.forseti}/profile/manage`}>自分のアカウント</a>を開きます。
2. **プレイヤー名**、国、都市、任意の連絡先や天鳳情報を更新します。天鳳は公開ユーザー名のみを入力し、ログイン文字列を入力しないでください。
3. アバターを有効にし、256 KB 以下の正方形の画像を選びます。他の形は中央の正方形に切り抜かれます。
4. **変更を保存**し、完了表示を待ちます。

<GuideScreenshot name="account-profile" alt="名前、System ID、国、都市、アバターのプロフィール画面。System ID はアカウントを一意に識別します。" caption="名前、System ID、国、都市、アバターのプロフィール画面。System ID はアカウントを一意に識別します。" height={930} />

メールはここでは変更できません。変更はサービスの統括管理者へ連絡してください。アカウントを削除すると個人データは消えますが、すでに行った対局のデータは残ります。サービスの利用をやめる場合にのみ削除してください。イベント退会やパスワード変更には不要です。

<h3 id='password'>パスワードの変更・再設定は？</h3>

忘れた場合も変更したい場合も、メールによる再設定を使います。

1. <a href={`${env.urls.forseti}/profile/resetPassword`}>パスワード再設定</a>で登録メールを入力して送信します。
2. 届いたメールのリンクを開きます。
3. 確認画面で**パスワードをリセット**を押すと旧パスワードは使えなくなります。ページを離れる前に次の手順を終えてください。
4. 新しい安全なパスワードを入力し、**パスワードを更新**を押します。
5. 成功表示の後、新しいパスワードでログインします。

<GuideScreenshot name="account-password" alt="登録メールで再設定を申請する画面。届いたリンクから新しいパスワードを指定します。" caption="登録メールで再設定を申請する画面。届いたリンクから新しいパスワードを指定します。" />

期限切れ・使用済みのリンクは再申請してください。未着なら迷惑メールも確認します。

<h3 id='questions'>よくある質問</h3>

**アシスタントにイベントがありません。** 主催者に、現在のイベントへ正しいアカウントが追加されているか確認してもらい、一覧を更新するか設定で再選択します。

**主催者が私を見つけられません。** 分かりやすい名前を保存するか System ID を伝えます。別のアカウントは作成しないでください。

**結果はどこですか？** <a href={env.urls.sigrun}>ランキングと統計</a>でイベントを選びます。大会結果は管理者の承認後、公開設定に従って表示されます。
