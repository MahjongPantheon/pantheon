Prerequisties:
- Database name: frey / mimir
- Database user: same as database name
- Database password: pgpass

Databases are expected to be clean before import. You may use `bin/pantheon compose --profile tools up -d pgadmin.pantheon.internal` to delete tables in DBs through pgAdmin GUI.

Export:

$ PGPASSWORD=pgpass pg_dump -U frey2 -h 127.0.0.1 -p 5532 frey2 > frey2.sql
$ PGPASSWORD=pgpass pg_dump -U mimir2 -h 127.0.0.1 -p 5532 mimir2 > mimir2.sql

Import:

$ PGPASSWORD=pgpass psql -U frey2 -h 127.0.0.1 -p 5532 frey2 < frey2.sql
$ PGPASSWORD=pgpass psql -U mimir2 -h 127.0.0.1 -p 5532 mimir2 < mimir2.sql
